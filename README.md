|---|---|

| 지금 공개 중인 웹 교재 (v2 모아페이) | <https://voidmain443.github.io/git-github_for_PM_Tutorial_docs/> · 원본 [`금융PM_실습교재_신규개정/`](금융PM_실습교재_신규개정/README.md) |

## 작업 규칙

- 새 작업은 `v3/`에서만 합니다. `_보관/`은 고치지 않습니다.
- 원본은 마크다운입니다. PDF와 HTML은 결과물입니다.
- 학생이 읽는 글은 만든 뒤 `python3 v3/tools/budget_check.py <파일>`로 잽니다.
- 이 저장소는 공개입니다. 비공개 자료는 저장소 폴더 밖에 둡니다.
