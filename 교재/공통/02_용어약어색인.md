# 용어·약어·문서 ID 색인 — PM 트랙 4일 공용

> **쓰는 법** — 교재·워크북을 읽다가 낯선 약어나 `R-10`, `CR-09`, `A10`, `BL-02` 같은 ID가 나오면 여기서 찾는다. 약어는 알파벳순, ID는 접두어별로 묶었고, 마지막에 이 과정이 특별한 뜻으로 쓰는 우리말 용어 30개를 모았다. 각 항목의 "→"는 그 개념을 설명하는 교재의 날과 절이다. 정의는 이 과정에서 쓰는 뜻이며, 표준 원문의 정의와 어감이 다를 수 있다.

| LOE | Level of Effort | 노력 수준형 작업(PMO 등) — EV를 PV와 같게 인정 |

## 3. 이 과정이 특별한 뜻으로 쓰는 우리말 용어

| 용어 | 뜻 | → |
|---|---|---|
| 산출물 / 성과 / 편익 | output(만든 것) / outcome(그것이 쓰여서 달라진 것) / benefit(측정 가능한 가치) — 산출물까지가 PM의 책임 | D1 1.1 |
| 임시조직 | 끝이 정의된 조직으로서의 프로젝트 — 행동 논리가 상설 조직과 다르다 | D1 1.3 |
| 되돌림 비용 | 결정을 되돌리는 데 드는 비용 — 방법론·계획 정밀도·게이트 위치를 정하는 변수 | D1 1.5·2.6 |
| 테일러링 | 표준을 프로젝트에 맞게 생략·추가·조정하는 것 — 기록(TDR)이 있어야 테일러링 | D1 2.6 |
| 비즈니스 케이스 | 이 프로젝트에 돈을 쓰는 것이 조직에 이익인가를 답하는 문서 — 게이트마다 갱신 | D1 3.1 |
| 헌장 | 프로젝트의 존재·범위·권한을 승인하는 문서 — 계획서가 아니라 권한 문서 | D1 3.2 |
| 현저성 | Mitchell-Agle-Wood — 권력·정당성·긴급성 3속성의 조합으로 이해관계자가 얼마나 "보이는가" | D1 3.3 |
| 허용범위 | tolerance — 그 계층이 상위에 묻지 않고 흡수할 수 있는 편차의 크기(7축 × 3계층) | D1 3.4 |
| 예외 관리 | Manage by Exception — 허용범위 안은 알리지 않고, 넘을 것으로 예상되면 즉시 올린다 | D1 3.4 |
| 프리모템 | 사전 부검 — "실패했다, 왜?"의 과거형으로 리스크를 끌어내는 기법(Klein) | D1 3.5 |
| 기준선 | 승인되고, 버전이 있고, 변경 통제 아래 있는 계획 — 범위·일정·원가 | D2 1.1 |
| 경계 조건 | 범위의 안팎을 정하는 조건 — 제외 항목에는 담당 프로젝트가 붙는다 | D2 2.1 |
| 인수 기준 | 산출물을 받았다고 판정하는 조건 — 측정 가능, 판정자 실명 | D2 2.1 |
| 범위 크립 / gold plating | 승인 없이 늘어나는 범위 / 요구에 없는 것을 더 잘 만드는 것 | D2 2.4 |
| 여유(float) | 활동을 늦춰도 종료일이 밀리지 않는 기간 — 총여유는 경로의 것 | D2 3.2 |
| 컨틴전시 / 관리예비비 | 식별된 리스크용 PM의 돈(BAC 안) / 미식별 리스크용 스폰서의 돈(BAC 밖) | D2 4.2 |
| 계획 원가 / 집행 한도 / 승인 예산 | 145.8 / 156.0 / 168.0 — 온담 예산의 3층 | D2 4.2·4.5 |
| 견적 등급 | AACE Class — 정의도(설계 성숙도)로 정한다 | D2 4.1 |
| 잔여 노출 | 대응 후 남는 리스크의 EMV | D2 5.4 |
| 통제 사이클 | 측정 → 분석 → 예측 → 조치 → 기준선 갱신 | D3 1.1 |
| Rules of Credit | EV 인정 규칙 — 0/100, 50/50, 마일스톤 가중, 물리적 %, LOE | D3 2.2 |
| 착시 | 지표를 좋게·나쁘게 보이게 하는 구조적 원인 — 이름을 붙이고 조정값을 병기 | D3 2.6 |
| 재기준선 | re-baseline — 편차를 없애기 위해 기준선 자체를 다시 만드는 것(기준선 갱신과 다르다) | D3 3.4 |
| 변경 대가 | 승인된 변경에 대한 수행사 대금(FP × 단가) — 감액도 변경 | D3 3.5 |
| 원인 귀속 | 감리 지적·지연의 원인이 발주사/수행사/동시 중 어디에 있는가 — 검수·대기 비용 판정의 근거 | D3 4.3·5.6 |
| 동시기록 | 사건 당시에 서면으로 남긴 기록 — 구두 지시에 서면으로 답한다 | D3 5.5 |
| 이관 | 프로젝트가 만든 것을 운영이 받는 것 — 받는 쪽의 서명으로 끝난다 | D4 1.1 |
| 런북 / 컷오버 | 시각 단위 실행 절차서 / 구 시스템에서 신 시스템으로 넘어가는 전환 작업(온담 34시간) | D4 2.1 |
| 롤백 | 컷오버를 되돌리는 것 — 트리거·판정자·복구 소요를 사전 합의 | D4 2.4 |
| 두 번 컷오버 | 매장·주문(1차)과 물류(2차)를 나눠 전환 — R-14의 원천 | D4 2.7 |
| error budget | 가용성 목표를 뒤집은 허용 다운 시간(99.5% → 월 약 219분) — 릴리스 속도로 환전 | D4 3.6 |
| 분모 정치 | 어느 분모로 KPI를 재는가의 다툼 — 승인된 목표는 승인된 분모로 판정 | D4 5.6 |
| 손익분기 실현률 | 편익이 몇 % 실현되어야 NPV ≥ 0인가(온담 66%) | D1 워크북 ①, D4 5.7 |
