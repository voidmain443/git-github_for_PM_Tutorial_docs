# Product 트랙 제작 노트 — 주의할 점 (저자·강사용)

> 수강생에게 배포하지 않는다. Day5~8의 교재·워크북·슬라이드·템플릿을 만들 때와 강의할 때 지켜야 할 규칙, 설계된 함정, PM 트랙에서 가져온 교훈을 모았다. 수강생용 안내는 `10_Product_학습안내.md`, 계획은 `13_Product_4일계획.md`.

## 1. 정본과 우선순위

1. **숫자의 정본은 `가상회사_딥게이지.md` §7**(G·V·E·K ID)이다. 온담 쪽 숫자는 `가상회사_온담F앤B.md` §5. 두 정본에 없는 값은 워크북 완성 예시본이 `[추가 설정]`으로 정하고, 그 값은 `그림/Product_DayN/src/dayN_*.py` 검산 스크립트에 넣는다. 교재는 워크북 값만 인용한다(PM Day2의 교훈 — 병렬로 쓰면 갈린다).
2. **발명하지 않는 것** — 법령·표준·기관·인증 제도(ISO/IEC 25010·42001, TIPS 운영 요강, 개인정보 보호법, ISMS-P). 회사·인물·계약·사내 규정은 발명한다. 표준·문헌의 판본은 기억하지 말고 검색·인용 검증 도구로 확인한 뒤 쓴다(PMBOK 8판·ITIL v5의 교훈).
3. **시점을 고정한다.** Day5 D+0~90 / Day6 D+120~300 / Day7 데이터 일자 2027-10-23(D+600) / Day8 2028-05(47건·텀시트)와 2028-11-26(에필로그). 미래의 숫자를 앞날에 쓰지 않는다 — Day6 교재에 D+600의 채택률 22%가 나오면 안 된다.
4. **분모를 선언한다.** MRR·GM·AI 원가율은 순SaaS 기준이 검산값이고 계약 기준이 IR 표기값이다. 채택률은 분모 3종(㉮ AI 노출 건 22% / ㉯ 전체 검사기록 건 14% / ㉰ 활성 계정 처리 건 38%)이며 **절대 건수는 정본에 없다 — 만들지 않는다.** 코호트는 분모 정의를 표 첫 열에 쓴다.
5. **이름에 소속을 붙인다.** `[세영정공] 정미영 품질팀장` / `[온담] 정미란 CFO`. 인쇄물·슬라이드·템플릿 모두.
6. **의도된 오기는 고치지 않는다.** IR 덱의 61%·2.3개월·5.8:1·18.9억·15% 옵션풀은 그대로 둔다 — 그것이 학습 장치다. 대신 워크북 해설(X.6)에서 검산값을 병기하고 "왜 두 값이 다 산수로 맞는가"를 설명한다. §3 함정 대장에 없는 불일치는 실수이므로 고친다.

## 2. PM 트랙에서 가져오는 규약 (그대로)

- 교재 절 틀: 개념 → ■ 사례 사실 → 딥게이지의 사례로 읽기 → 실무에서 어떻게 틀리는가 → 표준·문헌. 장 끝: 한 줄씩 + 핵심 정리 / 생각해 볼 질문 / 워크북 연결(항목 단위). (심화)·(과정 후) 표시, 머리말 "읽는 법과 분량".
- 워크북: §0(사용법·따라가는 순서·마스터 표 40종·딥게이지 한 페이지 요약·**역할 전환 선언문**·**PM 트랙에서 가져오는 것**·PM/PO/PdM 용어 합의문) + 산출물 5 × (X.1 왜 / X.2 표준·문헌 위치 / X.3 항목별 가이드[무엇을·어떻게·흔한 오류·딥게이지에서는] + 📖 태그 / ◆ 실습 입력 카드 + ★ 수업 중 과제 / X.4 빈 템플릿 + PDF 경로 / X.5 완성 예시본(■ 먼저 쓰고 나서 펼치라) / X.6 해설 / X.7 실습). 양식은 `Product트랙/_워크북_양식.md`.
- 템플릿: `템플릿/Product_DayN/src/NN_body.tex` — 빈 템플릿은 이미 있다. 완성 예시는 워크북 X.5가 확정된 뒤 같은 body에 `\else` 가지를 채운다(`\B{빈}{완성}`, `\Bg{안내}{기입}`).
- 슬라이드: Beamer 직접 집필, 교시별 파일, 발췌만 읽기, append 3~4프레임, `\note`에 교재 § + 예상 소요 분. `%`는 `\%`, `\texttt`에 한글 금지. Day5에만 0교시(역할 전환 20분) — 1교시 80분·마무리 20분으로 540분.
- 그림: TikZ·matplotlib(`그림/Product_DayN/src`, common.tex·mplcommon.py 복제). 코호트 삼각행렬·North Star 트리·캡테이블 워터폴·5차원 표·UE 두 열은 그림으로.
- 글리프: Apple SD Gothic Neo에 있는 것만(■ ◆ ● ▶ ★ → ✓ § 가능, 작은 삼각형(U+25B8)·체크박스(U+2611)·긴 화살표(U+27F6)·📖 불가 — 📖·📄는 book.lua가 ▶로 치환). ㉑~㊵은 빌드 전에 렌더 확인 — 없으면 book.lua에 치환 추가.

**판정 규칙(헌법 §8.1을 잇는다)**: 해설은 정답을 쓰지 않고 **즉시 탈락 조건**과 **방어 가능한 답의 범위**를 쓴다. 예 — 시드 5억 배분: 탈락 = 분모를 하나도 확인하지 않고 3분할 / 망점 칸에 숫자 / 표본 정의 공란인 회사에 배분. 정답 처리 = 익명 A를 판독 불가로 두고 두 곳에만 배분("무배분은 무판정이 아니다"). 오답 처리 안 함 = 자사 3:2, 2.5:2.5, B에 더 많이. 47건 3분류: 탈락 = ②(마스터 없음)를 제품화·커스텀으로 / ④(법정 기준)에서 배상 메모 미연동 / 5차원 표 없이 개별 판정.

## 4. 날별 주의

- **Day5** — 역할 전환은 산출물이 아니라 선언과 서명이다(워크북 §0에 선언문, ㉑ 항목 9에 서명). 인터뷰 27건 원자료는 워크북 §0.3에 요약으로 준다 — 27건 전문을 만들지 않는다(역할군별 인용문 3~5개 + 관찰 기록 + 박선재 카드). "아직 없는 회사"이므로 PM 트랙의 사례 정본 §5 같은 운영 지표가 없다 — 문제 크기 4숫자와 시장 숫자만 있다. 이 빈약함이 정상이며 교재 1장에 그렇게 쓴다.
- **Day6** — 백로그 41건 견적표는 [추가 설정]으로 워크북이 정본. Appetite는 기간 고정(6개월)이지 범위 고정이 아니다(Shape Up의 어휘를 정확히). eval 명세서의 데이터셋 정의에 "자동차 3세트"를 **학생이 쓰게** 하되 그 함의는 말하지 않는다(F-11). 밸류메트릭 4안 비교는 표로, 선택의 대가(라인 과금이 점포에 맞지 않음)는 Day8까지 말하지 않는다.
- **Day7** — 코호트 3장은 물리적으로 구별되지 않게(같은 격자, 같은 망점 위치, 분모 인쇄 고정). 익명 A의 분모 정의는 "물으면 답한다"(워크북 카드에 "분모 정의는 §X.5에 봉인 — 먼저 표본 정의 칸을 채우라"). 사고 보고서는 8D 형식(PM 트랙 번역 사전 — 8D = 포스트모템). 첫 PM 채용은 배경 사건으로만.
- **Day8** — 두 시점을 섞지 않는다. 47건 목록 자체보다 5차원 표가 산출물의 본체. ㊵는 PM ⑳의 표를 그대로 가져와 output 열을 채운다 — 온담 편익 B-02 재고 정확도(분모 A 91.3 → 98.5 / B 84.6)와 딥게이지 output(검사기록 자동 생성률·코드 매핑 커버리지)을 한 표에. 마지막 30분은 Day3 분모 정정으로 되돌아간다.
    - 제작 결과 메모: 시점 1 = 2028-05-10(D+800) — 정본 §7.1의 'D+900' 열 값을 그대로 쓴다(D+800~900 사이 갱신 없음). 정본 4.10의 RFI는 표기 D+640이나 날짜 2027-11-02 = D+610 — 날짜를 정본으로. 47건의 차원 태그·공수·부담·분류(제품화 14/27 mm · 유상 19/59 · 거절 14/52)는 워크북 ㊱ 별지가 정본. 옵션풀 post 비교의 방식(320억 pre를 풀 없는 FD에 적용, 한강도 희석 분담 → 18.71 / 25.79 / 1.29%p)은 정본 §7.5에 명시했다 — 이전 판의 26.00 / 19.26 / 0.74%p는 재현 불가여서 폐기. K-05 강민수 27.01·윤하경 9.00은 정본 표기(계산 27.015 · 9.005). 에필로그(D+1000)는 워크북 §7 봉인 — ㊱ 항목 5의 '예측' 줄을 학생이 먼저 적게 한다.
