# PM 트랙 Day2 교재 그림 목록

- 위치: `교재/그림/PM_Day2/` (PNG 200dpi + PDF 벡터), 소스는 `src/` (.tex = TikZ standalone, .py = matplotlib)
- 교재 본문(`PM트랙/Day2_교재.md`)에서는 `../그림/PM_Day2/<파일>.png` 상대경로로 참조한다. 슬라이드(Beamer)에서는 같은 이름의 `.pdf`를 `\includegraphics`로 넣으면 벡터로 들어간다.
- 재빌드: `cd src && ./build.sh fig_3_2_cpm_g2_g3` (확장자 제외, 여러 개 나열 가능). 공통 프리앰블 `src/common.tex`, 공통 mpl 설정 `src/mplcommon.py`는 Day1의 것을 복사했다(같은 색·스타일). 루트 `교재/build.sh figs`도 PM_Day1·PM_Day2 두 디렉터리를 모두 돈다.
- 색: navy #1F3A5F / teal #2A7F62 / rust #C8553D / grey. 모든 그림 하단에 출처 표기.

## 교재 PDF 빌드 시 유의 (pandoc)

- Day1과 같다 — 본문 md의 U+2212(−)는 Apple SD Gothic Neo에 없으므로 빌드 전 치환(build/book.lua 또는 sed). 그림 소스에서는 `$-$`로 처리했고, 캡션에는 ASCII 하이픈을 썼다.
- `implicit_figures`를 끄고 이탤릭 캡션 줄을 쓰는 Day1의 방식을 그대로 따른다(alt 텍스트와 캡션 줄이 같은 번호를 갖는다).
- 가로가 긴 그림(3-5 달력, 3-6 전체 네트워크, 2-4 WBS, 5-4 격자)은 pandoc 기본 `\includegraphics[width=\textwidth]`로 들어가면 글자가 작아진다. Day1의 hdr_*.tex가 그림 폭을 텍스트 폭으로 맞추므로 인쇄 시 확인하고, 필요하면 해당 그림만 가로 페이지(`\begin{landscape}`)로 돌린다.
