# 가독성 개편(2026-09-13) — 삽입 블록의 데이터와 스크립트

사람이 순서대로 읽으며 따라갈 수 있게 교재·워크북에 넣은 안내 블록의 **정본 데이터**다. md 본문을 직접 고쳤으므로 다시 실행할 필요는 없지만,
Product 트랙(Day5~8)을 같은 틀로 만들 때 이 파일들을 복제해 쓴다.

| 파일 | 내용 | 들어간 곳 |
|---|---|---|
| `xref_map.py` | 워크북 산출물 §n·항목 N → 교재 절 번호 | 워크북 X.1 아래 "📖 먼저 읽기", 항목 제목 아래 "📖 교재 n.n절(제목)" |
| `wb_cards.py` | 산출물 20종의 ◆ 실습 입력 카드(정본 § / 앞 산출물 / 추가 조건 / ★ 수업 중 과제) | 워크북 X.3 끝, X.4 빈 템플릿 앞 |
| `facts.py` | 교재 온담 소절 51곳의 "■ 사례 사실" 줄(사실 + 출처) | 교재 `### 온담…` 소절 제목 바로 아래 |
| `oneliners.py` | 18개 장의 "한 줄씩" 핵심 정리 | 교재 `## 제N장 핵심 정리` 바로 아래 |
| `tiers.py` | 절 등급 — (심화) 절 목록, (과정 후) 장 목록 | 교재 목차와 절·장 제목 뒤 |
| `patch_workbooks.py` | 위 데이터로 워크북에 블록을 삽입한 스크립트(멱등: 이미 있으면 건너뜀) | — |
