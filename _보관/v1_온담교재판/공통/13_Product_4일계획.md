## 0. 트랙의 한 문장

**PM 트랙이 "이미 있는 회사가 결정된 것을 문서로 세우고 분해하고 측정하고 이관하는 4일"이었다면, Product 트랙은 "아직 없는 회사가 무엇을 만들지, 무엇을 만들지 않을지, 얼마를 받을지, 어떤 숫자로 자기를 속이지 않을지를 정하는 4일"이다.** 같은 수강생이 Day4까지 발주자였고 Day5부터 공급자다. 8일의 마지막 문서(㊵)는 PM 트랙의 마지막 문서(⑳)와 같은 표에 양쪽이 서명하는 것이다.

## 4. 날마다 반드시 들어가는 것

### Day5 — 프리시드
- **0교시 역할 전환 선언** (사례 §3.0 대본): "당신은 어제까지 이 계약의 발주자였고, 오늘부터 공급자다. 시계를 33개월 되감는다." 워크북 §0에 **역할 전환 선언문**과 **PM/PO/PdM 용어 합의문**을 둔다.
- 교재 1장: 프로덕트 매니지먼트가 프로젝트 관리와 다른 점을 **결정의 종류**로 설명한다 — 무엇을 만들지(발견) / 얼마나 만들지(범위) / 얼마를 받을지(가격) / 무엇으로 성공을 잴지(지표). 표준 지형: Cagan(Inspired), Torres(Continuous Discovery), Christensen(JTBD), Moesta(네 가지 힘), Rumelt(전략 커널), 그리고 PM 트랙의 편익 원장과의 대응.
- 인터뷰 27건은 워크북 §0.3 상황에 **원자료 요약(역할군별 인용문·관찰)**으로 주어진다 — 학생이 발명하지 않는다. 박선재 인터뷰의 "자기 보고 vs 관찰" 괴리가 ㉒ 항목 6.
- 해법 명사 금지 규칙("태블릿", "OCR", "앱"이 들어간 기회 문장은 무효)을 ㉓의 검증 열로.
- 세그먼트 결정: 도면 클라우드 금지(김도윤) → 온프렘 수용 vs 세그먼트 회피. ㉕에 "하지 않는 것"을 적게 한다.
- 창업 합의서(㉑): 옵션풀 pre/post 미명시가 첫 함정. 베스팅 4년·1년 클리프를 학생이 정한다.

- ㊳·㊴: ARR 18.9 vs 15.68, 집중 리스크 3표기(37% / 24.1% / 82%), 캡테이블 T3 두 안, 옵션풀 pre 1.29%p, "온담 거절 = 코너스톤 텀시트 소멸".
- ㊵: PM ⑳의 표에 딥게이지가 output 열을 채우고 양쪽이 서명. FN 2.4%의 모집단(자동차 60건 / 온담 4세트 미측정) → 측정 계획을 인수 기준 조항으로.
- 마지막 30분: 8일 최종 명제. 20종 + 20종 사슬을 거꾸로 추적(㊵ ← ⑳ ← ① … / ㊵ ← ㉗ ← ㉖ ← ㉓ ← ㉒).

## 5. 교재 절의 고정 틀 (PM 트랙과 동일)

각 절: 개념 → **■ 사례 사실** → 딥게이지의 사례로 읽기 → 실무에서 어떻게 틀리는가 → 표준·문헌에서는. 장 끝: 핵심 정리(**한 줄씩** 상자 + 자세한 판) / 생각해 볼 질문 / 워크북 연결(항목 단위). 절 제목에 (심화)·장 제목에 (과정 후). 공식 절에는 "작은 숫자로 먼저". 머리말에 읽는 법과 분량(필독 100~140분).

## 6. 제작 순서 (PM 트랙의 교훈)

워크북(숫자 정본, python 검산 — `그림/Product_DayN/src/dayN_*.py`) → 교재(워크북 값만 인용) → 그림·템플릿 완성예시 → 슬라이드(교시별 파일, 발췌만 읽기, 3~4프레임/append) → 책 빌드 → 중괄호 균형·Overfull 매핑·beamer2md 미러·컨택트 시트. 빈 템플릿은 이 계획과 함께 **먼저** 만들어 두었다(`템플릿/Product_DayN/`).
