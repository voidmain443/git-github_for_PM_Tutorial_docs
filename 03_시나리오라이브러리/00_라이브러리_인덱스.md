# 시나리오 라이브러리 — 인덱스와 선택 가이드

기수의 수강생 구성을 보고 골라 쓰는 가상 프로젝트 카탈로그다. 각 시나리오는 **4일(9시간×4) 완결형**이며 헌장부터 종료보고서까지 산출물이 누적된다.

모든 시나리오는 동일한 11개 섹션 구조를 따른다: 세계관 → 롤카드 → 4일 아크(캔버스/의사결정/인젝트/디브리핑/학술후크/표준매핑/carry-forward) → 데이터팩 → 인쇄팩 → 루브릭 → 도메인 리딩 → 도메인 인사이트 → 강사 함정 → 프로덕트 트랙 연결 → 검증 필요 항목.

> **주의**: 라이브러리 시나리오는 [설계 헌법](../00_과정설계/00_설계헌법.md)의 산출물 3등급 상한(필수3/선택4/참고2)과 인젝트 상한(하루 2~4개)이 **아직 적용되지 않은 원안**이다. 캔버스 16~20종, 인젝트 14~16개는 9시간×4일에 들어가지 않는다. 실제 개설 전 반드시 헌법 1·4·5조로 다이어트하라. 원안은 "무엇을 버릴지 고르기 위한 재고 목록"으로 쓴다.

### HDX-1: 용인 100MW 하이퍼스케일 데이터센터 신축
- **ID**: `construction-datacenter` / **난이도**: 고난도
- **한 줄**: 이미 이사회 승인이 끝난 1조 3,200억, 100MW 하이퍼스케일 IDC. 당신은 예산 전결권 3억짜리 발주사 PM으로 임명됐고, 하루 지연은 5억 4,700만원이며, 한전 계통·발전기 74주 납기·주민 민원·앵커 테넌트의 RFS 약정이 당신의 공정표를 대신 짜고 있다. 4일 동안 헌장부터 종료보고서까지 벽 하나에 세운다.
- **4일 아크**: D1 착수 — 숫자가 없는 헌장은 소설이다 → D2 일정 — 여유(Float)는 누구의 재산인가 → D3 실행 — 진척률은 왜 항상 90%에서 멈추는가 → D4 인수와 종료 — 불이 들어와야 프로젝트다
- **캔버스 총수**: 20종 / **롤카드**: 11장 / **인젝트**: 16개

### HSB-301 글로벌 3상: 되돌릴 수 없는 게이트
- **ID**: `pharma-clinical-csv` / **난이도**: 고난도
- **한 줄**: 매출 8,400억 중견 제약사 한성바이오파마가 아토피피부염 신약 HSB-301의 5개국 92기관 3상(1,120명, USD 78M)을 수행하면서, 15년 된 자체 EDC(HCTMS 1.0)를 글로벌 SaaS 플랫폼으로 갈아타야 한다. 규제 게이트는 비가역이고, 등록은 계획의 절반이며, QA는 풀 밸리데이션을, CFO는 IR 날짜를, CMO는 프로토콜 불변을 요구한다.
- **4일 아크**: D1 착수: 권한 없이 시작하기 — 헌장, 비가역 게이트, 임계품질요인 → D2 소싱과 검증 전략: 남의 손으로 하는 프로젝트, 남의 소프트웨어로 만드는 기록 → D3 실행과 통제: 등록은 절반, EVM은 붉고, 개정은 92개 IRB를 흔든다 → D4 실사와 종료: 3주 후 실사관이 온다, 그리고 DB Lock은 한 번뿐이다
- **캔버스 총수**: 16종 / **롤카드**: 13장 / **인젝트**: 14개

### 가온은행 차세대 코어뱅킹 전환 — PROJECT GAON NEXT
