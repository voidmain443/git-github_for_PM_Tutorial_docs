# 학습 여정과 문서의 변화를 보여 주는 랜딩

> 이 문서는 앞선 랜딩 개정의 이력이다. 현재 구현과 검증은 [결과 미리보기와 학습 가이드](결과미리보기_랜딩과_학습가이드.md)를 따른다.

2026-09-27. 대상은 PM 입문자이며, 처음 방문한 사람이 자신이 할 일과 학습 후 남길 문서를 이해하고 0단원에 진입하는 것이 목적이다.

## 디자인 계획

- 색: 잉크 #173443, 종이 #f8faf8, 회청 #e7eeec, 소나무 #176a62, 황동 #d4a653, 슬레이트 #607480. 금융 운영 문서의 차분함과 검토 표시를 시각 언어로 삼는다.
- 글꼴: 한국어 시스템 산세리프를 일관되게 사용한다. 큰 제목은 짧은 문장과 조밀한 자간, 본문은 충분한 행간으로 구분한다. 장식용 영문 라벨을 늘리지 않는다.
- 배치: 왼쪽에 학습 약속, 오른쪽에 문서가 연결되는 작업 공간을 둔다. 아래에는 한 프로젝트의 학습 여정, 실제 사용 화면, 전체 단원, 마지막 문장 비교를 차례로 읽는다. 긴 글은 왼쪽 정렬한다.

```
공통 탐색
학습 약속 + 시작 버튼  |  문서 작업 공간 + 단계 선택
회사에서 맡은 일      |  무엇을 만들어 남기는가
다섯 학습 구간 선택   |  입력 → 수행 → 검토 → 산출물
실제 화면 사용 안내
0~9단원으로 찾아가기 / 시작 안내
초안의 문장          |  근거를 반영한 문장 + 수정 과정
나의 프로젝트 기록 / 학습 시작
```

## 계획을 검토한 결과

일반적인 교육 광고의 성과 숫자·동일 카드 나열·반복 스크롤 애니메이션 대신 모아페이의 실제 문서와 학습자의 작성 행동을 중심에 둔다. 입체 표현은 문서의 연결을 보여 주는 한 장면에 집중한다. Blender 모델의 외형보다 수정 가능한 문서 형태가 목적에 맞아 Three.js의 코드 기반 형상으로 만든다. 외부 모델·텍스처를 다운로드할 필요 없이 동일한 가벼운 자산을 재현한다.

D3는 학습 구간을 바꿀 때 원천·수행·검토·산출물이 어떻게 연결되는지 보여 준다. 학습 전후의 표현은 교육용 부분 예시로 표시하고, 실제 수강생의 성과나 향상률로 제시하지 않는다. 홈페이지 조작은 ERP 시점·원천자료·학습자 작성본을 변경하지 않는다.

## 품질 기준

서버·외부 CDN 없이 GitHub Pages 하위 경로에서 동작한다. 3D는 명시적으로 선택한 뒤에만 다운로드하며, WebGL을 사용할 수 없으면 정적 그림과 동일한 설명을 제공한다. 애니메이션은 짧게 끝나며 화면 밖·숨긴 탭·동작 줄이기 설정을 존중한다. 키보드로 모든 단계를 고르고 전후 문장을 비교할 수 있다. 모바일에서는 원문을 자르거나 작은 글씨로 축소하지 않는다.

교재·ERP·시각화 워크북·자료실의 탐색과 표면 스타일을 일관되게 정리하되, 읽기·조회·작성 동작과 시점별 공개는 유지한다. 홈의 실제 화면 안내도 변경된 UI에 맞춰 다시 촬영한다.

기술 참고: [Three.js WebGLRenderer](https://threejs.org/docs/pages/WebGLRenderer.html), [D3 transitions](https://d3js.org/d3-transition). 공급 라이브러리는 버전·라이선스·해시를 함께 보관한다.


## 구현 뒤 화면 검토

실제 1440px·390px 화면을 열어 첫 화면, D3 여정, 세 버전 문장 비교, 교재 본문, ERP, 시각화 워크북을 확인했다. 첫 CTA의 글자 대비와 SVG/3D 중첩 문제를 수정하고 자동 회귀 검사에 추가했다. 모바일 교재의 반복 과제 설명을 한 곳으로 모으고 사용법을 펼침 안내로 바꿨다. 워크북은 선택한 단원이 보이는 가로 메뉴로 줄이고 소개 영역의 안쪽 여백·한글 줄바꿈을 보완했다.

홈의 실제 안내 GIF를 최종 교재·ERP 화면으로 다시 촬영했다. Pages 954개 검사와 로컬/브라우저 조회 431건이 통과했다. 근거 문장·예시의 교육적 적합성은 S0 문서와 독립 대조했으며, 실제 학습 효과는 입문자 파일럿에서 확인할 항목으로 남긴다.
