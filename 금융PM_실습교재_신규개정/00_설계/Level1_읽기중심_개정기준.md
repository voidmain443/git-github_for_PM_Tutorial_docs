# Level 1 읽기 중심 개정 기준 · 2026-09-24

## 학생이 따라가는 순서

학생은 0단원부터 본문을 읽고, 같은 단원의 실습을 수행한 뒤 다음 단원으로 이동한다. 본문은 업무 상황·개념, 원천자료 읽기, 부분 작성 예제, 교육용 검토, 수정과 권한, 독립 수행과 인계의 여섯 절로 구성한다. 총 10단원 60절이다. 이미 개념을 이해한 학생은 단계별 실습으로 바로 전환할 수 있다.

69개 실습 단계는 한 번에 `개념 읽기 → 근거·예제 → 작성·검토` 중 한 화면을 보여 준다. 원천 문서와 ERP 조회는 근거 화면에서, 확인 문제와 편집·내려받기 양식은 작성 화면에서 제공한다. 정답 입력, 조회 기록, 완료 체크를 다음 단계 이동의 조건으로 삼지 않는다.

문서 작성은 실제 학습의 핵심이지만 웹 입력은 선택이다. 같은 페이지에서 단원·단계를 바꿔도 선택형 초안은 메모리에 남는다. 페이지를 떠나거나 새로고침하기 전에 파일로 내보내고 다음에 불러온다. 서버 제출이나 학생별 자동 평가·추적은 하지 않는다.

## 단원별 본문과 독립 수행

| 단원 | 함께 읽고 작성할 핵심 | 학생이 이어서 수행할 일 | 선택 시각화 위치 |
|---|---|---|---|
| 0 회사에 합류하기 | 사람·업무·세 종류의 돈, ST001 정산 산식 | 다른 정산·대사 건을 조회하고 G00에 근거와 해석 남기기 | `sources` 정산 흐름 |
| 1 프로젝트 착수 | 목표 문장·권한·범위, 검토와 승인 구분 | D01·A01·D30 작성, 수정 후 S16/AP00 조건 대조 | `charter-10` 검토·승인 |
| 2 요구사항과 범위 | R01의 요구·인도물·시험 연결 | 나머지 요구 추적과 WBS·사전 작성, 경계 검토 | `5.2` 요구 연결 |
| 3 일정과 자원 | 선후관계·전진/역진 계산·여유, C 활동 부분 계산 | 전체 활동·날짜·자원을 계산하고 실행 가능성 검토 | `6.5` 네트워크·간트 |
| 4 원가와 예산 | C 원가, 11월 비용과 현금의 차이 | 전체 추정·예비비·월별 자금 연결 및 중복 집계 점검 | `7.3` 비용·현금 |
| 5 품질과 리스크 | K01 기록, 품질의 방법·증거, 확률과 등급 구분 | K02와 네 시나리오 계산, 품질·대응을 일정·예산에 반영 | `11.4` 위험 시나리오 |
| 6 조달과 협업 | 기술평가 한 칸, 선정 권고와 계약 권한 | 나머지 제안 평가·계약 검토·수신자별 협업 계획 | `12.2` 업체 평가 |
| 7 계획 통합과 실행 | 분야 계획 대조, 승인·지시·실적 구분 | 킥오프 결정을 작업으로 옮기고 실행 증거·후속 관리 연결 | `9.3` 실행 증거 |
| 8 성과와 변경 통제 | PV·EV·AC 해석, 변경 요청과 결정의 차이 | 대안·영향 분석, 승인 후 관련 문서와 기준선 갱신 | `4.6` 변경 대안 |
| 9 검수·이관·종료 | 검증·현업 인수·종료 승인의 다른 책임 | 인수·계약 종결·이관·교훈·편익 추적 책임 인계 | `5.5` 인수·이관 |

3~4단원의 계획은 5~6단원 검토 후 다시 갱신하고 7단원에서 통합한다. 실행·통제·종료에서는 품질·자원·소통·리스크·조달·참여 기록을 계속 사용한다. 단원 순서를 프로세스 그룹과 프로젝트 단계의 일대일 대응으로 설명하지 않는다.

## 시각화를 줄이는 기준

단원 본문에는 자동 실행 그림을 배치하지 않는다. 각 단원의 핵심 실습 한 곳에서 목적을 설명하고 선택해서 열게 한다. 닫힌 그림은 불러오지 않고 닫으면 실행 문서를 제거한다. 같은 그림을 모든 실습 단계에 반복하지 않는다. 별도 시각화 워크북은 관계 확인과 조건 비교가 필요할 때 이용한다.

시각화 선택값은 ERP 원본·승인 기준선·문서 승인 상태를 바꾸지 않는다. 현재 시점에서 근거가 공개된 경우에만 추천한다. 예를 들어 7단원의 실행 증거 도구는 S2 활동에 연결하며 S1A 킥오프 단계에 먼저 표시하지 않는다.

## 원천과 설명의 경계

교육용 검토 대화는 새로운 회사 사건이나 실제 회신으로 오해하지 않도록 표시한다. 부분 예제만 공개하고 전체 표와 다른 사례는 독립 수행으로 남긴다. 실제 결정은 해당 원천의 승인자·버전·효력일로 확인한다.

본문 각 절과 실습 단계 모두 공개 시점을 가진다. 현재 시점보다 뒤의 절은 제목과 필요한 자료 시점만 제공하고 본문·예제는 JSON에서 제외한다. 시점 선택은 회사 정보 공개 순서이며 학생의 성적이나 문서 승인 여부를 뜻하지 않는다. 공개 웹의 시점 구분은 접근 권한 통제가 아니다.

## 제작 검증과 수업 검증

원천 수치·역할·시점 대조, 문서 연결 검사, 웹·로컬 SQL 일치, 브라우저의 화면 전환·선택형 도구·모바일 표시, 단계별 배포본 분리와 PDF 렌더링을 제작 검증으로 수행한다.

실제 초심자 파일럿은 별도다. 0~1단원부터 설명 없이 시작할 수 있는지, 원천을 찾는 데 어디서 멈추는지, 사실·판단·승인을 구분하는지, 검토 후 문서를 스스로 수정하는지를 관찰한다. 다음으로 2~9단원을 수행하면서 소요 시간·도움 요청·잘못된 인계를 기록한다. 소요 시간을 아직 실측하지 않았으므로 수업 일수나 교육 효과를 확정하지 않는다. 기존 `Level1_고도화_완료기준과_후속레벨.md`의 파일럿 기준과 함께 사용한다.
