# 결과가 보이는 랜딩과 학습 가이드

## 새 디자인의 판단

앞선 랜딩의 종이 모형과 문장 비교는 문서의 외형과 문장을 보여 주지만, PM이 새롭게 할 수 있는 판단을 충분히 드러내지 못했다. 이번에는 첫 화면 자체를 실습 산출물의 전시·조작 공간으로 만든다. 헌장의 관계도, 계산된 간트, 성과와 변경 판단을 실제로 보여 준 뒤 어느 메뉴에서 같은 종류의 실습을 수행하는지 연결한다.

## 색·타입·배치

- 심해색 #152447: 제목과 결과의 핵심. 코발트 #3056c9: 선택·연결·계획. 구름색 #f4f6fc: 페이지 배경. 흰색 #ffffff: 작업 결과. 슬레이트 #59677e: 설명. 황금색 #e5bd62: 검토가 필요한 조건.
- 한국어 본문은 Apple SD Gothic Neo / Malgun Gothic / system sans, 17px 이상·1.85 행간으로 읽는다. 제목은 같은 계열의 굵은 48~56px, 한 문장 전체를 같은 색으로 두고 작업 결과가 시선을 끈다. 숫자는 tabular-nums로 비교한다.
- 메인 상단은 짧은 소개와 시작 버튼, 이어서 가로로 넓은 결과 실습판이다. 실습판 안의 왼쪽은 입력 메모, 오른쪽은 결과 시각화다. 모바일은 결과가 먼저 보이고 입력 메모가 그 아래로 이어진다. 별도 전후 카드 나열을 반복하지 않는다.
- 사용 안내는 230px 목차와 800px 이내 본문의 2열. 모바일은 목차가 위로 오며, 번호가 붙는 것은 실제 순서뿐이다. 각 메뉴의 사용 시점·클릭·확인·남길 것을 같은 구조로 읽는다.

```
로고                     교재 / ERP / 시각화 / 사용안내 / 자료실
첫 프로젝트의 결과물을 직접 만들어보세요.          시작 / 사용안내
[헌장 만들기] [일정 연결하기] [성과 판단하기]
┌ 입력 메모 ───────────┬ 검토할 수 있는 시각화 결과 ────────────┐
│ 모호한 주장 / 빠진조건 │ 목표·범위·권한 / 선후간트 / EVM 비교 │
│ 내가 확인할 질문       │ 원천 → 분석 → 연결 → 결과 재생       │
└────────────────────┴───────────────────────────────────────┘
어떤 판단을 할 수 있게 되는가 / 어떤 메뉴에서 연습하는가
교재 → ERP → 시각화 → 교재의 작성·검토 → 자료실 보관
실제 화면 안내 / 10단원과 산출물
나의 완료 판단 기준 / 시작
```

## 일반 템플릿과 비교한 수정

큰 홍보 문구·추상적 종이 오브젝트·텍스트 전후 카드에 집중했던 구성을 바꾼다. 눈에 띄는 요소는 한 개의 결과 실습판이다. 나머지는 메뉴를 선택하는 이유와 학습 순서를 설명한다. 문구를 반복하는 카드·장식 그라데이션·역량 상승률·자동 스크롤 효과를 넣지 않는다. 사용자의 조작에 반응하는 유한한 재생과 실제 계산으로 변화의 이유를 설명한다.

## 예시의 경계와 구현

헌장·일정·성과 사례는 PREVIEW-01 ‘정산 알림 개선’이라는 별도 가상 사례다. 실제 학습 프로젝트 MP-01의 미래 자료·승인 결과·완성 답안과 섞지 않는다. 페이지에 사례의 단위·가정·검토용 상태를 표시한다. 미리보기 조작은 ERP 시점·원본·작성본·브라우저 저장소를 변경하지 않는다. 실습으로 이동하면 기존 시점 공개 규칙을 그대로 따른다.

D3는 산출물의 값·관계·전환을 그린다. 앞선 Three.js 종이 모형은 공개 배포에서 제외한다. 결과는 정지 상태로 먼저 읽을 수 있고, 재생은 사용자가 시작한다. 단계 선택·다른 사례 선택·화면 밖·탭 숨김은 재생을 멈춘다. 감소 동작에서는 단계별 정지 설명으로 동일 내용을 제공한다.

홈과 사용안내 모두 목적별 메뉴 안내, 실제 조회·작성 예, 저장·검토·자료시점 규칙을 제공한다. 기존 홈 GIF와 교재·ERP의 기능을 유지한다. 실제 데스크톱·모바일에서 결과 그림, 목차, 긴 문단, 버튼 대비를 확인한 뒤 배포한다.

## 구현 후 검토

데스크톱과 모바일에서 세 결과판, 사용 안내 목차, 실제 조회→작성 흐름을 확인했다. 밝은 간트 막대의 글자는 어둡게 바꾸고 메뉴 설명의 크기·명암비를 높였다. 계산식의 항목명과 학습 전 비교 문장도 같은 기준으로 보완했다. 교재 이동에는 과업 ID를 명시해 이전 읽기 위치로 잘못 복귀하지 않게 했다. 새 화면으로 사용 안내 GIF 5개·24컷을 다시 촬영했다.

PM의 능력 변화는 목표·범위·권한, 선후관계·여유·지연 영향, 진척·원가효율·대안을 설명할 수 있는지로 제시한다. 시각화의 수치 변화가 실제 수강생의 학습 효과라는 인상을 주지 않도록 독립 사례와 검토용 상태를 표시했다. 실제 교육 효과와 수업 소요시간은 입문자 파일럿에서 확인할 후속 항목이다.
