# 작성과 시각화를 연결하는 문서 결과 개정

## 목표

작은 설명 그림을 실무 문서의 완성형처럼 제시했던 간극을 줄인다. PM 문서는 목적·범위·기준일·버전·책임·근거·검토 의견·결정 요청을 담아야 다른 사람이 검토할 수 있다. 시각화는 같은 문서 안에서 추적 관계, 일정 영향, 성과 차이를 설명한다. 이번 개정은 세 가지 밀도 있는 비교 예시와 실제 작성·실습 결과의 문서화 경로를 함께 제공한다.

## 화면 설계와 판단

색상은 기존 학습 사이트와 연결되는 잉크 #152447, 코발트 #3056c9, 흰 종이 #ffffff, 작업대 #edf1f7, 본문 #45546b, 미결 표시 #946318을 쓴다. 표와 차트에는 같은 지표를 같은 색으로 표시한다. 한국어 시스템 고딕은 본문 16px/1.85, 문서 표 13~14px/1.65, 제목 30px, 문서 번호와 수치에는 tabular-nums를 사용한다. 본문은 왼쪽 정렬하고 긴 문장은 약 70자 폭으로 읽는다.

```
문서 결과 비교  [헌장] [일정 기준선 검토] [성과·변경 보고]
[간단한 요약과 비교] [검토 문서]            [인쇄] [HTML 보관]
짧은 작성 지침 / 근거·가정 / 실습으로 이동
┌ 문서 차례 ───┬ 문서 번호·버전·기준일·검토 상태 ──────────┐
│ 요약          │ 결정 요청 / 작성·검토·승인 책임            │
│ 범위·추적     │ 본문과 요구·인수 기준표                    │
│ 일정·숫자     │ 실제 관계를 계산한 일정/성과 차트 + 원본표 │
│ 검토·결정     │ 미결 항목 / 검토 처리 / 개정 이력 / 근거   │
└───────────────┴───────────────────────────────────────────┘
```

동일 크기 카드나 큰 성과 숫자 중심의 랜딩 구성을 반복하지 않는다. 특징은 **검토자가 실제 읽는 밀도의 문서 자체**다. 조작은 대안을 선택하거나 문장을 편집할 때만 결과에 반영한다. 원안과 제안의 값·버전·승인 상태를 동시에 읽고, 문서의 서술과 수치가 서로 충돌하면 확인할 항목을 남긴다. 그래프는 스크롤 영역과 텍스트 표를 함께 제공하여 모바일에서도 축소된 작은 글씨를 강요하지 않는다.

## 세 경로의 구분

- 문서 결과 비교: 독립 가상 사례 PREVIEW-02. 처음부터 검토 문서의 형태를 보되 실제 MP-01 미래 답안과 구분한다. 공개 1차 지침은 문서 구조를 정하는 참고이며, 사례의 수치·내부 정책은 교육용으로 창작한다.
- 시각화 워크북: 현재 ERP 시점에서 실제로 조작한 결과에 학습자의 해석·권고·미결 사항을 더해 문서로 묶는다. 조건이 달라지면 해석을 다시 확인하도록 알리고 명시적으로 결과를 갱신한다. 원천 ERP와 승인 기준선은 변경하지 않는다.
- 교재 작성: 학습자 자신의 Markdown 초안을 문서처럼 미리 보고 수정한다. 빈칸을 채워 주거나 승인·서명을 생성하지 않는다. 기존 Markdown 보관과 독립 HTML·인쇄 경로를 제공한다.

## 검증 기준

독립 예시의 예산·기간·EVM·대안 합계와 표의 근거를 계산 검사한다. 현재 시점의 문서와 그림만 결과에 들어가며, 숨겨진 계산이나 미래 승인 자료를 내보내지 않는다. 편집한 문장과 파일 결과는 같아야 한다. 본문·표·SVG·한글·인쇄 경계를 실제 화면에서 검토한다. 기존 교재·ERP·양식·모바일·시점·저장 규칙의 회귀 검사를 유지한다. 실제 학생의 학습 효과는 별도 파일럿 항목이다.


## 구현과 검토 결과

세 문서의 본문 각 여섯 절과 검토 의견·개정 이력·원천을 구현했다. 일정 그림은 기존 일정 계산 함수를 공유하며 네 가지 안을 비교한다. 원가 추이는 보고일까지의 실적과 이후 계획을 구분한다. 실제 시각화 워크북의 열 개 모듈은 공개된 결과만 명시적으로 복사하고, 입력한 해석·권고·미결 사항과 묶어 HTML로 보관한다. 전체 양식은 기존 표/원문 편집기에서 작성하고 문서 미리보기로 검토한다.

화면 검토 중 문서 영역을 넓히고, SVG의 최소 읽기 폭을 유지해 간트와 표의 글자가 과도하게 작아지는 문제를 보완했다. 모바일의 본문은 16px를 유지하고 넓은 표·그림에만 가로 이동을 제공한다. 보고서에는 원천자료와 작성자의 판단을 나누어 표시하며 미작성 칸과 미승인 상태를 그대로 남긴다. 비교 예시·워크북 메모·교재 양식의 용도와 저장 방법을 사용 안내에 연결했다.

Pages 1088개 검사와 조회 비교 431건이 통과했다. 추가 83개 브라우저 검사는 초안과 출력 일치, 미래 자료 제외, 기준선 보존, 수치·조건 변경 후 재반영, 모바일·키보드·HTML 입력 안전성을 포함한다. 문서 결과의 풍부함과 실제 학생의 능력 향상은 별도 평가한다.
