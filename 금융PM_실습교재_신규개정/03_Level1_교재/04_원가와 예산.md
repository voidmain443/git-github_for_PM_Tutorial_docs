# 04. 원가와 예산

최민석은 “비용이 얼마인지와 언제 현금을 준비해야 하는지를 각각 보여 달라”고 요청합니다. 통장 잔액만으로 예산을 작성할 수는 없습니다.

원가 추정은 앞으로 필요한 작업 비용을 계산하는 일입니다. 원가기준선(Cost Baseline)은 승인된 비용 계획이며 실제 비용을 비교하는 기준입니다. 발주는 구매 약정, 검수는 받은 용역의 확인, 청구는 공급자의 대금 요청, 지급은 현금 유출입니다. 같은 거래의 서로 다른 사건이므로 합산하지 않습니다. 식별 위험을 위한 우발예비비와 예상하지 못한 업무를 위한 관리예비비도 서로 다른 위치에서 관리합니다.

이 단원은 설명 → 자료 조회 → 예제 → 직접 확인 → 검토·수정 → 다음 업무 순서로 진행합니다. 웹 입력은 필요하지 않습니다. 문서를 작성할 때는 양식을 내려받고 같은 문서의 버전을 이어 갑니다.
