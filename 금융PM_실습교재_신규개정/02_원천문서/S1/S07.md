# S07 | 품질·리스크 워크숍 원문

공개: S1 계획 검토 · 버전1.1 · 작성P06 / 검토P07 / 확인P03

이 문서는 실습 입력이다. 사실의 확인자와 학습자가 작성할 산출물의 승인자를 혼동하지 않는다.

정유나: 산출물 품질은 R01~R05 인수조건으로 판단하고 매주 금요일 요구-설계-테스트 연결을 점검하자. 치명 결함0, 권한 테스트8/8, 거래 표본480/480, 예외12/12, 운영자3/3이 오픈 조건이다.
리스크 K01 외주 인터페이스 불일치 확률0.30 비용영향10백만원 일정5일, 책임이현우. K02 테스트 환경 지연 확률0.20 비용영향20백만원 일정10일, 책임정유나. 독립 발생을 가정한다. 발생 전 대응은 각각 모듈 구현 전 표본검증(초기 준비 업무로 수행하고 기존 설계 예산에 포함), 환경 사전점검(기존 QA 업무 내)이다. 학습자는 독립 가정으로 발생하지 않음·각각 발생·동시 발생 네 경우의 확률과 기대금액을 계산하고, 제안된10백만원 우발예비비가 어느 정도의 손실을 담보하는지 설명한다.
정성 우선순위 척도: 실제 확률×영향등급(저1/중2/고3)을 사용한다. K01의 비용영향 등급은 중2, K02는 고3이다. 실제 확률과 영향등급을 곱해 점수를 계산하며 동일점수면 일정영향이 큰 위험을 먼저 점검한다. 정량분석은 실제 확률을 쓴다. 위험 발생조건: 표본검증 불합격 또는 환경 인계일 지연. 사건 발생 후에는 이슈로 전환한다.
