# S18 | 범위 분해와 시험 설계 협의 기록

공개: S1 계획 검토 · 버전1.1 · 작성P05 / 검토P06 / 확인P03

이 문서는 실습 입력이다. 사실의 확인자와 학습자가 작성할 산출물의 승인자를 혼동하지 않는다.

2026-10-12 / 박다은·이현우·정유나·오수빈 협의. 학습자는 아래 설명을 WBS 사전과 요구 추적표로 변환합니다.
요구·설계 패키지는 R01~R05 업무 명세, 인터페이스 규격, 화면·권한 설계와 검토 기록을 인도하며 개발책임자가 완료를 확인합니다. 조회 패키지는 R01 조회와 R04 권한·로그 구현을 인도합니다. 대사·예외 패키지는 R02/R03 모듈과 소스·단위시험 증거를 인도합니다. 검증 패키지는 통합시험과 보안 회귀시험 증거를 인도하며, 각 모듈의 개발 비용을 여기서 다시 세지 않습니다. 전환·교육 패키지는 운영 매뉴얼, 복구 절차, 교육 확인을 인도합니다. 안정화 패키지는 운영 관찰과 미해결 사항 인계를 포함합니다. 모든 패키지 완료 확인 후 현업이 통합 인수를 판단합니다.
WBS 코드는 S06의 1.1~1.6을 부서 간 연결 키로 사용합니다. 분해 수준을 더 세분해도 이 상위 코드는 보존합니다. 계획 단계 담당은 1.1·1.2 이현우, 1.3 공급사 역할(계약 전 회사 선정 미확정), 1.4 정유나, 1.5 박다은, 1.6 이현우입니다. 발주사는 운영 인수에 계속 책임을 집니다.
시험 설계 번호는 T01 정산금액, T02 대사 분류, T03 예외 필수정보, T04 접근권한·로그, T05 운영 인수입니다. 계획 시 시험 방법과 기대결과만 적으며 실제 통과 수와 인수 서명은 작성하지 않습니다. 조회·대사에는 9월30일의 24가맹점·480거래 표본을 사용합니다. T04의 기존 포털 시험은 S17의 경계를 적용합니다.
T04 설계: 운영 조회 허용, 운영 예외수정 허용, 가맹점 자기내역 조회 허용, 가맹점 타사조회 차단, 가맹점 예외수정 차단, 미인증 조회 차단, 감사 이력조회 허용, 감사 이력삭제 차단. 변경로그 필수값은 행위자·시각·사유입니다.
T05 표준업무: 날짜·가맹점 조회, 대사결과 확인, 예외 담당·기한 지정, 처리사유 기록, 복구 절차 시연. 세 운영자 각각 다섯 업무를 수행해야 하며 다른 사람이 대신한 결과는 그 사람의 합격 증거가 아닙니다.
요구사항 담당자가 해석을 확인하고 개발·QA가 수행·검증 가능성을 검토합니다. 이 협의는 범위 기준선 승인과 다릅니다. 일정·예산·리스크·조달 계획과 맞춘 뒤 윤서진에게 통합 상정합니다.
