# S02 | 조직·권한·문서 규정

공개: S0 착수 전 · 버전1.1 · 작성P02 / 검토P04 / 확인P01

이 문서는 실습 입력이다. 사실의 확인자와 학습자가 작성할 산출물의 승인자를 혼동하지 않는다.

프로젝트코드 MP-01, 회사코드 1000, 통화 KRW. 모든 수치는 교육용 가정이다. 공휴일 효과를 별도로 적용하지 않는 월~금 달력을 사용한다. 문서 ID·버전·작성자·검토자·승인자·효력일을 기록한다. 회의록은 의제/사실/결정/담당자/기한을 구분한다.
헌장과 프로젝트 기준선 승인자는 윤서진이다. 범위·일정·원가 기준선의 변경은 크기에 관계없이 PM 영향분석→최민석·이현우·박다은 검토→윤서진 승인 순서다. 변경관리위원회는 이 네 검토·승인 역할과 PM으로 구성한다. PM의 일상 작업 배정과 기존 기준선 내 일정 상세화는 이슈·작업 기록으로 처리한다. 승인 전 변경 구현은 금지한다.
정산 인수는 박다은, 보안 검토는 오수빈, 테스트 증거는 정유나가 담당한다. 외주 계약은 강태훈 작성, 최민석 검토, 윤서진 서명. 팀원 문제는 먼저 당사자 면담 후 개발책임자와 자원 조정한다. 문서 저장소가 정본이며 구두 결정은 당일 회의록으로 확인한다. SLA: 일반 질의 2영업일, 정산 오류·보안 결함 당일 보고. 이는 법규 인용이 아닌 가상회사 내부 규정이다.
