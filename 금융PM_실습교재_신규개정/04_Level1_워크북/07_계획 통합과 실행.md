# 07. 계획 통합과 실행 - 문서 실습 안내

교재의 단계별 설명을 읽은 뒤 실제 산출물을 작성합니다. 웹에 다시 입력하거나 이 워크북에 본문을 중복 복사할 필요는 없습니다.

## 분야별 계획을 하나의 실행 가능한 계획으로 맞추기 (4.2)

사용 문서: D02 통합관리계획. 근거: S02, S06, S07, S08.

확인할 수행: 개발 C의 인원·공수와 일정, 위험 대응과 예비비의 포함 여부를 비교하세요. 분야 검토가 끝나도 지금 S1에서는 통합 승인 대기입니다.

검토: 초안 “문서가 모두 있으므로 승인 가능” → 상호 모순을 확인하지 않았습니다 → 요구→WBS→활동→비용→시험과 자원·계약 조건을 대조한 결과를 추가합니다.

## 킥오프 결정을 담당자에게 실행 가능한 지시로 넘기기 (4.3)

사용 문서: D03 작업·이슈 기록. 근거: S09, S02.

확인할 수행: 환경점검 결정을 같은 형식으로 작성하세요. 작업과 이슈를 다른 행으로 관리하고 S2의 S20을 받은 뒤 완료일과 확인자를 대조합니다.

검토: 초안 “킥오프 당일 환경점검 완료” → 지시와 실제를 혼동했습니다 → 지시 기록을 보존하고 실행 증거 수신 시 상태를 갱신합니다.

## 계획한 자원의 배정 확인서를 대조하기 (9.3)

사용 문서: D22 배정·교육·팀 기록. 근거: S06, S09, S20.

확인할 수행: D22에 환경 준비 증거와 운영지원 배정 조건을 연결하세요. 종료 때 해제할 배정과 운영에 넘길 자원을 구분합니다.

검토: 초안 “계획 인원 수를 실제 확보 수에 복사” → 확보 근거가 없습니다 → 확약 문서·일자·적용 기간을 함께 기록합니다.

## 교육 참석과 실제 수행 능력을 구분하기 (9.4)

사용 문서: D22 배정·교육·팀 기록. 근거: S08, S10, S20.

확인할 수행: 교육받은 내용을 실제 업무에 적용할 후속 활동을 정하세요. 운영자 인수 시연과 팀원 로그 교육은 대상과 목적이 다릅니다.

검토: 초안 “교육 참여로 역량 확보 완료” → 과업 수행 증거가 빠졌습니다 → 실습 결과와 이후 업무 적용을 분리해 적습니다.

## 팀의 어려움을 사실과 합의한 행동으로 기록하기 (9.5)

사용 문서: D22 배정·교육·팀 기록. 근거: S10, S20.

확인할 수행: S20의 양측 발언에서 각자의 필요를 하나씩 찾아 합의문을 작성하세요. 개인학습은 발언을 읽고, 팀학습은 같은 발언으로 역할 활동을 진행할 수 있습니다.

검토: 초안 “개발자는 협조적이지 않다” → 인물 평가로 바뀌었습니다 → 질문 대응이 집중시간에 미친 영향과 조정한 업무 방식을 기록합니다.

## 경험을 다음 사람이 사용할 교훈으로 남기기 (4.4)

사용 문서: D04 교훈등록부. 근거: S05, S10, S20.

확인할 수행: S05의 과거 교훈 한 건이 이번 계획 어디에 반영됐는지 찾고, S20 면담에서 다음 PM에게 넘길 적용 조건을 작성하세요.

검토: 초안 “질문 취합으로 생산성 향상 확인” → 후속 측정이 없습니다 → 합의된 방식과 아직 검증할 효과를 구분합니다.

## 품질 결과를 만드는 업무 절차를 점검하기 (8.2)

사용 문서: D19 품질감사·개선기록. 근거: S07, S10, S20.

확인할 수행: 질문 취합 방식이 바뀐 이유·담당·후속 확인을 D19에 적으세요. S10에서 발견한 DF01은 D20에 최초 발견·영향·조치를 기록하고 9단원에서 최종 이력을 완성합니다.

검토: 초안 “시험 18건 통과, 품질 관리 종료” → 실패와 절차 개선이 빠졌습니다 → 검사 결과와 작업 절차 점검을 나누고 각각 후속을 지정합니다.

## 회의 결과와 보고를 상대가 행동할 수 있게 정리하기 (10.2)

사용 문서: D23 의사소통계획·배포기록. 근거: S09, S10, S20.

확인할 수행: D23의 수신자별 계획을 사용해 작업회의 요약과 가맹점 안내를 각각 한 문단으로 써 보세요. S20의 발송·확인 원장에서 실제 수신 상태를 연결합니다.

검토: 초안 “발송했으므로 전달 완료” → 상대의 확인이 없습니다 → 발송일·확인일·미확인 후속을 별도 기록합니다.

## 예방조치의 실행 증거를 확인하고 위험 기록 갱신하기 (11.6)

사용 문서: D25 리스크등록부·보고서. 근거: S09, S10, S20.

확인할 수행: K02에 대해서도 계획·지시·실행·확인자를 연결하세요. 실행한 예방조치가 위험을 완전히 없앤 것인지 근거로 판단합니다.

검토: 초안 “예방 완료이므로 위험 삭제” → 잔여 위험을 잃습니다 → 최초 평가·실행 증거·잔여 평가를 나란히 남깁니다.

## 새로운 요청을 듣고 다음 협의로 연결하기 (13.3)

사용 문서: D31 참여계획·평가. 근거: S10, S11.

확인할 수행: 운영과 가맹점의 관심을 구분해 설명할 내용을 정하세요. 요청·답변·결정이 어디에 기록되는지 D31과 D06을 연결합니다.

검토: 초안 “만족도를 위해 요청 기능을 즉시 약속” → 승인 전 범위가 늘어납니다 → 필요를 확인하고 영향 분석·결정 시점을 안내합니다.
