# 06. 조달과 협업 - 문서 실습 안내

교재의 단계별 설명을 읽은 뒤 실제 산출물을 작성합니다. 웹에 다시 입력하거나 이 워크북에 본문을 중복 복사할 필요는 없습니다.

## 외주에 맡길 결과와 계약 조건 정하기 (12.1)

사용 문서: D27 조달계획·SOW. 근거: S06, S08, S19.

확인할 수행: 검수·보완·보증·지급·변경 조항을 D27에 쓰세요. 지급을 언제 요청할 수 있는지와 실제 현금 지급은 다른 사건입니다.

검토: 초안 “30백만원에 필요한 기능 전부 개발” → 범위가 열려 있습니다 → R02/R03과 인도물·제외·변경 절차를 구체적으로 적습니다.

## 같은 기준으로 제안을 평가하고 선정 권고하기 (12.2)

사용 문서: D28 제안평가·계약검토. 근거: S08, S19.

확인할 수행: 두 업체의 합계와 권고 이유를 계산하세요. D28 계약 검토에 S19의 납기·검수·보증·지급 조건을 남기고 서명은 S1A 자료를 받은 뒤 연결합니다.

검토: 초안 “가장 싼 업체로 발주 완료” → 평가와 계약 절차가 생략됐습니다 → 사전 가중치로 선정 권고하고 계약은 미서명 상태로 둡니다.

## 상대가 필요한 내용으로 보고 계획 정하기 (10.1)

사용 문서: D23 의사소통계획·배포기록. 근거: S02, S08.

확인할 수행: S08의 주기와 S02의 공유 범위를 사용해 스폰서와 가맹점의 보고 행을 작성하세요. 미확인일 때 누가 언제 확인할지 정합니다.

검토: 초안 “전원에게 원가 상세표 공유” → 정보 목적과 범위가 맞지 않습니다 → 수신자별 판단에 필요한 요약과 확인 요청을 분리합니다.

## 이해관계자가 필요한 결정에 참여하도록 돕기 (13.2)

사용 문서: D31 참여계획·평가. 근거: S08.

확인할 수행: 스폰서와 가맹점의 관심과 권한을 D30에서 찾아 각자에게 맞는 참여 활동을 적으세요. 실제 상태 변화는 실행 증거가 생긴 뒤 갱신합니다.

검토: 초안 “매일 같은 회의에 전원 참석” → 사람마다 필요한 결정이 다릅니다 → 승인회의·시연·요약 확인 등 역할별 활동으로 나눕니다.
