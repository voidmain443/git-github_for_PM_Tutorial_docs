# 홈의 실제 화면 안내 검토 · 2026-09-24

홈에서 본문 읽기 → 원천 문서 → ERP 조회 → 작성·보관 → 검토·인계를 다섯 단계로 선택한다. 각 단계는 실제 S0 화면을 조작해 촬영한 GIF와 정지 컷, 클릭 위치·확인할 내용·다음 업무 설명, 해당 실습으로 이동하는 링크를 제공한다.

- 1040×640 실제 화면 24컷, GIF 다섯 개. 합계 59.2초이며 각 단계는 7.4~14초다.
- 초기 화면과 수동 컷 이동에서는 GIF를 요청하지 않는다. 선택해서 재생하며 반복 재생 확장을 포함하지 않는다.
- 정지·수동 컷 이동·다른 단계 선택·화면 이탈 시 정지·개별 GIF 다운로드를 제공한다.
- 확대창은 현재 컷의 강조 대상을 중심으로 연다. 작은 화면에서는 가로·세로 스크롤로 주변을 확인한다.
- 안내 보기에는 ERP API나 학습자 저장소를 사용하지 않는다. 실제 실습 링크는 회사 자료 시점을 유지하며 지정한 과업·탭으로 이동하고 제목에 초점을 둔다.
- 녹화 안내와 실제 입력, 다운로드 요청과 파일 보관 확인, 검토 완료와 문서 승인을 구분해 설명했다.

최종 캡처의 프레임 수·시간·크기·GIF 단회 재생을 확인했다. 공개 빌드는 미디어 목록과 GIF 해시를 검증한다. 총 미디어는 약 2.86MB이며 원본 PNG·예시 작성 파일은 배포하지 않는다.

전체 Pages 검사 648개와 로컬/브라우저 조회 비교 431건이 통과했다. 이어 실습 링크의 제목 초점·스크롤을 보완한 최종본에서 홈 안내 전용 171개 검사를 통과했다. 390px 화면에서 확대 대상이 보이는지도 직접 검사하고, 데스크톱·모바일·확대 화면을 렌더링해 확인했다. 독립 검토에서도 다섯 링크의 정확한 도착 위치와 안내/실습 상태의 구분을 확인했다.

새 기능 검증은 `tools/home_tour_check.cjs`에 포함되며 기존 Pages 자동 배포 검사에서 함께 실행된다. 화면의 구조나 버튼명이 바뀌면 `capture_home_tour.cjs`와 `encode_home_tour.py`로 미디어를 갱신하고 캡처의 강조 위치를 다시 확인한다.
