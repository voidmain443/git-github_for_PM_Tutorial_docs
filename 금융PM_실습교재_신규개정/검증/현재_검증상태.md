## 재검증 순서

1. 원고·자료 변경 시 tools/rebuild.py --pdf --package로 자료·흐름·읽기 연결 검사와 배포본을 생성한다.
2. tools/reader_browser_check.cjs로 현재 화면 흐름을 확인한다.
3. tools/pdf_check.py로 PDF를 렌더링하고 변경된 페이지를 눈으로 확인한다.
4. tools/release_check.py로 실제 학생 ZIP만 독립 실행한다.
5. 이 색인과 개선항목 처리 결과를 갱신한 뒤 tools/package.py로 강사 전체팩에 최신 기록을 포함한다.

Python 제작·실행 환경과 PDF의 한글 글꼴 설정은 README_실행환경.md에 따른다. 학생 서버 실행에는 Python 표준 라이브러리만 필요하다.
