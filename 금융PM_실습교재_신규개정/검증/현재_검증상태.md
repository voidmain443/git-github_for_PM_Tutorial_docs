이 파일은 최신 결과의 색인이다. 60절 본문·69개 실습 단계·49개 프로세스에 설명 그림을 연결했다. 집필·기능·독립 배포 검사와 화면 검토를 마쳤으며 **실제 입문자 파일럿과 수업 시간 측정은 실시 전**이다.

그림 검사는 모든 노드·관계·원천·문단 위치와 일곱 자료 시점의 공개 경계를 확인했다. 순차 관계가 잘못된 공통선으로 합쳐지는 오류도 검사한다. 브라우저에서는 20개 그림의 실제 글자 경계, 320·390px 모바일의 세로 배치와 16px 본문, 선택형 시뮬레이션의 독립 동작을 확인했다. 실제 PNG를 열어 의미를 오해하게 하는 화살표도 수정했다. 배포 환경의 소수점 글꼴 배치에서 연결된 실습 제목이 화면 위로 일부 벗어나는 문제를 재현했고, 제목 이동 여백과 회귀 검사로 보완했다.

PDF 전체를 이미지로 렌더링하고, 공개 시점에 맞는 그림이 정확히 한 번 들어가며 그림·해설·적용 질문이 같은 페이지에 있는지 검사했다. 벡터 노드 텍스트와 한글 추출·본문 경계를 확인하고 대표 그림 페이지를 직접 시각 검토했다. 쪽수와 자동 검사 수는 학습 효과의 증거가 아니다.

학생 ZIP 검사는 저장소 없이 빈 폴더에 실제 배포 ZIP만 풀고 서버 하나에서 일곱 시점을 차례로 열었다. 해당 시점의 SVG만 포함되며 미래 그림·강사용 자료가 섞이지 않는지 확인했다. 시작팩은 S0, 추가팩은 이후 시점의 누적 자료다.

## 최신 문서 결과·작성 검토

전체 Pages 브라우저 검사 **1088개**와 로컬/브라우저 조회 비교 **431건**이 통과했다. 새 문서 결과·작성 연결 검사 83개를 포함한다. 문서 사례의 CPM·네 가지 대안 날짜·WBS 예산·EV·AC·현금 연결·지수 및 재추정 EAC·미래 실적 제외는 별도 계산 검사도 통과했다.

PREVIEW-02의 헌장·일정·성과/변경 문서를 1440px와 390px에서 직접 읽었다. 문서 차례·버전·기준일·작성/검토/결정 권한·결정 요청·본문 표·시각화·검토 의견·개정 이력·근거를 한 문서로 연결했다. 긴 간트를 좁은 종이에 축소하던 문제를 수정해 데스크톱 읽기 폭을 늘리고 모바일은 그림과 넓은 표만 가로 이동하게 했다. 실제 데이터가 없는 미래 EV·AC는 선으로 연장하지 않는다.

실제 교재의 표 입력·원문 수정·Markdown 재불러오기→문서 미리보기→HTML의 내용 일치, 사용자 입력 이스케이프와 키보드 조작을 확인했다. 워크북에서는 시점 잠금, 공개 전 계산 답안 제외, 현재 그림·근거·해석의 결합, 조작값 변경 시 이전 출력 잠금 및 재반영, HTML 파일 안의 SVG·조건·문장 보존을 확인했다. 초안·조작값은 서버·저장소에 쓰지 않는다. 예시 문서의 가상 승인과 학생의 실습 승인도 혼용하지 않는다.

내려받은 HTML을 데스크톱·390px 모바일·인쇄 미디어에서 확인했다. 세 문서 예시와 워크북 보고서에 표·SVG·근거 누락과 바깥 영역 넘침이 없었다. 헌장·성과 그림은 A4 가로 서식으로 바꾸어 인쇄 시 작은 글씨를 보완했다. 연속 재생 중 캡처 후 다운로드가 잘못 비활성화되던 문제는 재생 정지와 복사 순서를 고치고 회귀 검사로 확인했다. 홈 작성 GIF에는 문서 미리보기 한 컷을 추가해 총 25컷이 되었다.

이번 검토는 웹·독립 HTML의 기능과 화면/인쇄 미디어 표현 검사다. PDF 파일의 쪽 나눔을 새로 검증한 것은 아니다. 기존 교재 PDF·단계별 ZIP 수치는 아래 앞선 개정의 검증을 그대로 기록하며, 새 예시를 인쇄 교재의 답안으로 추가하지 않았다. 실제 수강생의 학습 효과나 교육 수행 시간은 별도 확인이 필요하다. 설계: [문서 결과 워크북 개정](../00_설계/문서결과_워크북_개정.md).

## 앞선 랜딩·가이드 화면 검토

메인 상단에서 미완성 메모와 헌장·간트·성과보고의 구조화한 결과를 비교한다. 별도 가상 사례 PREVIEW-01을 사용하며 실제 MP-01의 미래 자료·답안·승인과 연결하지 않는다. 개발 기간과 실제원가를 바꾸면 간트·총여유·CPI·EAC가 다시 계산된다. 네 단계 설명은 사용자가 재생하며 정지·직접 선택·동작 줄이기·화면 밖 정지를 지원한다. 조작은 원본·자료 시점·브라우저 저장소를 변경하지 않는다.

사용 안내는 목차와 읽기 영역을 분리하고 17px 본문으로 구성했다. 다섯 메뉴의 사용 시점·누를 순서·확인·남길 것을 설명한 뒤, S0 ST001 조회 → 금액 해석 → G00 부분 작성 → 검토·수정 → 보관·인계를 여섯 단계로 따라간다. 실제 화면 세 장은 확대해 읽을 수 있다. 웹 초안은 자동 저장되지 않는다는 점, CSV와 작성본의 차이, 다음 자료 시점, 일곱 가지 문제 해결을 포함한다. 함께 하는 ST001과 직접 수행하는 ST002/TX002001을 구분했다.

전체 Pages 검사 1003개와 로컬/브라우저 조회 비교 431건이 통과했다. 랜딩 199개·가이드 64개 집중 검사에는 키보드 입력, 모바일, JS 미사용, D3 로딩 실패 시 계산·텍스트 유지, S0 시작, 저장소 보존, 실제 ST001 한 건·222,440원 조회와 교재 복귀를 포함한다. 페이지 예외·누락 자산은 0건이다. 마지막 링크 보완 후 집중 263개 검사와 계산 검사도 다시 통과했다. 배포 Action도 동일 전체 검사를 실행한다.

1440px·390px 화면에서 세 결과와 가이드 첫 조회 흐름을 직접 확인했다. 검토 중 비주공정 간트 글자와 메뉴 설명의 낮은 명암비를 고치고 회귀 검사를 넣었다. 메뉴 설명은 11px 이상이며 중간 폭에서는 접는다. 비교 문장과 계산식 라벨도 어둡게 조정했다. 새 교재·ERP 화면으로 GIF 5개와 24컷을 재촬영했으며, 결과 만들기 모션과 화면 사용법 안내는 각각 선택해서 볼 수 있다.

헌장·일정·성과의 교재 링크에 과업 ID를 명시해 이전 읽기 위치와 무관하게 해당 작성 방법으로 연결한다. 앞선 Three.js 종이 모형은 공개 배포에서 제외했다. 원고·수치·PDF·독립 ZIP 항목은 앞선 본문 그림 개정의 검증이며 이번 웹 변경은 해당 원고나 PDF에 내용을 추가하지 않는다. 기능 검사 수는 실제 수강생의 문서 작성 능력 향상을 측정한 결과가 아니다. 디자인과 근거는 [결과 미리보기와 학습 가이드](../00_설계/결과미리보기_랜딩과_학습가이드.md)에 있다.

## 재현과 남은 검증

1. `tools/rebuild.py --pdf --package`로 원고·자료·그림·시점 검사와 인쇄·배포본을 만든다.
2. `tools/build_pages.py`와 `npm run test:pages`로 실제 공개 하위 경로와 동일한 브라우저 흐름을 검사한다.
3. `tools/pdf_check.py`로 PDF를 렌더링하고 변경된 그림 페이지를 직접 확인한다.
4. `tools/release_check.py`로 실제 ZIP만 독립 실행한다.
5. 교재 순서대로 처음 배우는 수강생이 어디서 멈추는지 관찰하고, 개념 설명·조회 안내·완료 기준을 보완한다.

구현·그림 배치 근거는 [본문 설명 그림 배치](../00_설계/본문_설명그림_배치.md), 공개 운영 방법은 [Pages 안내](../README_GitHub_Pages.md)를 따른다. 2026-09-23 이전의 점검 문서는 당시 버전의 이력이며 최신 검사 수로 사용하지 않는다. Level 2~4 상세 교재·데이터 제작은 후속 범위다.
