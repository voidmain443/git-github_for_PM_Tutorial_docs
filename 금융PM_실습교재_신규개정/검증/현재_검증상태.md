그림 검사는 모든 노드·관계·원천·문단 위치와 일곱 자료 시점의 공개 경계를 확인했다. 순차 관계가 잘못된 공통선으로 합쳐지는 오류도 검사한다. 브라우저에서는 20개 그림의 실제 글자 경계, 320·390px 모바일의 세로 배치와 16px 본문, 선택형 시뮬레이션의 독립 동작을 확인했다. 실제 PNG를 열어 의미를 오해하게 하는 화살표도 수정했다. 배포 환경의 소수점 글꼴 배치에서 연결된 실습 제목이 화면 위로 일부 벗어나는 문제를 재현했고, 제목 이동 여백과 회귀 검사로 보완했다.

PDF 전체를 이미지로 렌더링하고, 공개 시점에 맞는 그림이 정확히 한 번 들어가며 그림·해설·적용 질문이 같은 페이지에 있는지 검사했다. 벡터 노드 텍스트와 한글 추출·본문 경계를 확인하고 대표 그림 페이지를 직접 시각 검토했다. 쪽수와 자동 검사 수는 학습 효과의 증거가 아니다.

학생 ZIP 검사는 저장소 없이 빈 폴더에 실제 배포 ZIP만 풀고 서버 하나에서 일곱 시점을 차례로 열었다. 해당 시점의 SVG만 포함되며 미래 그림·강사용 자료가 섞이지 않는지 확인했다. 시작팩은 S0, 추가팩은 이후 시점의 누적 자료다.

## 재현과 남은 검증

1. `tools/rebuild.py --pdf --package`로 원고·자료·그림·시점 검사와 인쇄·배포본을 만든다.
2. `tools/build_pages.py`와 `npm run test:pages`로 실제 공개 하위 경로와 동일한 브라우저 흐름을 검사한다.
3. `tools/pdf_check.py`로 PDF를 렌더링하고 변경된 그림 페이지를 직접 확인한다.
4. `tools/release_check.py`로 실제 ZIP만 독립 실행한다.
5. 교재 순서대로 처음 배우는 수강생이 어디서 멈추는지 관찰하고, 개념 설명·조회 안내·완료 기준을 보완한다.

구현·그림 배치 근거는 [본문 설명 그림 배치](../00_설계/본문_설명그림_배치.md), 공개 운영 방법은 [Pages 안내](../README_GitHub_Pages.md)를 따른다. 2026-09-23 이전의 점검 문서는 당시 버전의 이력이며 최신 검사 수로 사용하지 않는다. Level 2~4 상세 교재·데이터 제작은 후속 범위다.
