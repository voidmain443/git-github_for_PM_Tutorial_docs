# Level 1 웹 통합 교재 검토

기준일: 2026-09-24. 실제 입문자 파일럿을 대신하지 않는 제작자 기술·내용 검토입니다.

## 이번 개정

- 10개 단원의 개념 도입 30절, 69단계 심화 설명 207절 및 해설형 자기확인 69문항을 같은 원고에서 웹·PDF로 생성합니다.
- D3 7.9.0 기반 10개 시각화 실습을 단원 안에 펼칩니다. 원천 ID·시점·단위·연습 가정과 후속 양식을 표시합니다.
- 웹 양식은 실제 표 편집과 Markdown 파일 왕복을 지원합니다. 초안은 페이지 메모리 안에만 있으며 이동 전 미보관 변경을 알립니다. 조회·작성 내역을 서버에 저장하지 않습니다.
- 단원 전체 읽기에서도 미래 단계의 본문·확인문제를 표시하지 않습니다. 공식 승인과 실습 조작을 구분합니다.
- 4.4의 S20, 4.7의 S14·S17 원천 연결을 설계표에도 맞췄습니다. 위험 대응 작업 ID의 S20 출처, FS·지연0 계산 가정, S08 공유 제한 출처를 독립 검토 후 명확히 했습니다.

## 완료한 검증

- 자료 354/354, 수업 연결 472/472, 심화 읽기 교재 869/869 검사 통과.
- D3 계산 모델: 일정 여유·병렬 주공정·Lead/Lag·달력, EVM, 확률 경계·EMV·예비비 커버, 지급 총액 보존, 제안 평가.
- 브라우저: 253개 검사, SQLite와 431개 조회 결과 일치. 10개 내장/독립 실습, 69개 문항, 파일 편집·내보내기·불러오기·단계 간 유지·미보관 경고, 미래 잠금, 390px 화면, 동작 줄이기 포함.
- 별도 실제 데이터 검토: 6개 신규 실습의 재생·일시정지·초기화, 모듈 이동 시 타이머 정리, 시각화 HTML 내보내기.
- PDF 17개 전체 페이지 렌더·한글 추출·범위 검사, 교재/워크북 대표 페이지와 웹 일정·모바일 화면 시각 점검. 페이지 범위 초과 0건. 전체 교재 157쪽, 전체 워크북 89쪽; 공개 인쇄본은 선택 시점별로 분리합니다.
- 실제 학생 ZIP을 빈 폴더에 추출하고 한 서버에서 S0→S4를 순서대로 여는 독립 배포 검사. 상세 건수는 읽기교재_독립배포검증.json을 참조합니다.

## 남은 교육 검증

입문자 3~5명의 실제 수행을 관찰해 자료 검색·개념 이해·계산·문서 작성·검토 반영에 걸리는 시간과 막힌 지점을 수집해야 합니다. 다른 요구·거래·변경 항목으로 독립 수행이 가능한지도 확인합니다. 기술 검증 통과나 설명의 분량을 학습 성취로 표현하지 않습니다. 다음 제작은 Level 1 파일럿 보완 뒤 별도 Level 2 변경 사건팩부터 진행합니다.
