# Level 1 읽기 중심 개정 검토 · 2026-09-24

0~9단원에 여섯 절씩 통독 본문을 집필했다. 69개 실습 단계와 49개 프로세스는 유지하며 웹의 기본 화면을 본문 읽기로 변경했다. 실습은 개념·근거와 예제·작성과 검토를 나누고 시각화는 단원별 한 단계에서만 선택해 연다.

## 원고 검토

집필과 별도로 전체 60절을 원천자료의 수치·권한·시점과 대조했다. 정산 산식, 요구와 WBS·시험 연결, 일정 계산, 비용과 현금, 위험 평가, 조달과 승인 권한, EVM과 변경, 검수·편익 인계를 검토했다.

7단원 S1A 예제에 실제 원장번호 WO01-A가 미리 등장한 부분을 수정했다. 학생 임시 작업 ID로 먼저 작성하고 S2의 S20을 읽을 때 실제 번호와 대응시키도록 했다. 교육용 검토 대화는 새로운 회사 사건과 구분했다.

데스크톱과 모바일 본문·자료조회 화면을 직접 보며 한글 줄바꿈을 보완했다. PDF의 단원 개요표는 인계 설명 열을 넓혀 확인했다. 완전본 교재는 192쪽·워크북 91쪽이며, 웹 자료실의 S4 공개본은 교재 181쪽·워크북 78쪽이다. 단계별 공개본의 차이는 추가 참고자료·정답 해설 제외와 공개 범위에 따른다. 분량을 교육 효과의 증거로 사용하지 않는다.
