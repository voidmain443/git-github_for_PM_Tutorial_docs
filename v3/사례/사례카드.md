## 회사와 문제

모아페이는 2022년에 세운 결제·정산 회사입니다(가상의 회사). 직원 80명이 가맹점 240곳의 결제를 정산합니다. **정산**은 가맹점에 줄 돈을 계산하는 일이고, **대사**는 그 계산과 은행 기록이 같은지 비교하는 일입니다.

정산팀은 매일 **120분**을 파일 대조에 씁니다. 금액이 다른 거래(예외)는 매달 **12건**씩 담당자와 처리 이력 없이 남습니다.

## 프로젝트

| 항목 | 내용 |
|--------------|------------------------------------------------------------------------------------|
| 만드는 것 | 내부 정산 확인 화면, 자동 대사, 예외 처리 이력 |
| 바꾸지 않는 것 | 결제 승인 엔진, 수수료 계약 |
| 목표 | 종료 다음 영업일부터 **20영업일** 동안 하루 대사 시간 평균 **60분** 이하 · 예외 처리 이력 **100%** · 정산금 계산 정확도 100% |
| 돈 | 승인 한도 **132백만원** |
| 시간 | **2026년 10월 5일** 사업 제안 → **2027년 1월 22일** 종료 목표 |
| 편익 | 업무 시간 **월 180만원** 상당(3명 × 1시간 × 20일 × 시간당 3만원). 현금 절감이 보장되지는 않습니다 |
| 투자 판단 | 편익에서 시스템 운영비(**연 600만원**)를 빼고 나면, 투자금을 되찾는 데 **8년 넘게** 걸립니다. 대표는 추적성과 운영 신뢰를 함께 보고 추진을 결정했습니다 |

## 여러분의 자리

여러분은 이 프로젝트를 맡은 내부 PM **한지우**입니다. 무엇을 혼자 정하고 무엇을 올려서 승인받을지는 Day1에 헌장을 쓰며 자료에서 찾습니다.

## 돈의 세 종류 — 주인이 다릅니다

| 누구의 돈 | 예 | 답하는 질문 |
|--------------|------------------------------|------------------------------------------|
